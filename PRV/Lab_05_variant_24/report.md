# Лабораторная работа №5

## Титульный лист

**Дисциплина:** Параллельное программирование

**Вариант:** 24  
**Название:** Чат с поддержкой геолокации

## Задание

Разработать многопользовательский чат с отправкой местоположения.

Требования варианта:

- сервер хранит координаты пользователей;
- сервер поддерживает поиск по местоположению;
- клиент отправляет текущее местоположение;
- клиент отображает карту и маркеры;
- клиент выполняет поиск ближайших пользователей;
- поддерживается поиск по адресу.

Общие требования: использовать сокеты, поддерживать несколько клиентов одновременно, обрабатывать клиентов в отдельных потоках, показывать статус подключения и иметь документированный код.

## Введение

Геолокационный чат объединяет обычный обмен сообщениями с информацией о местоположении участников. Такая модель может использоваться для поиска коллег рядом, локальных групп и геочатов. Цель работы — реализовать сетевое приложение с TCP-соединением, потоковой обработкой клиентов и передачей JSON-событий.

## Теоретическая часть

Сервер использует TCP-сокет и протокол JSON Lines: каждое сообщение — один JSON-объект, завершённый символом новой строки. Для каждого клиента сервер создаёт daemon-поток `threading.Thread`. Общий словарь клиентов и координаты защищены `RLock`, а отдельная блокировка отправки предотвращает перемешивание JSON-пакетов при одновременных рассылках.

Расстояние между координатами вычисляется формулой гаверсинуса:

`d = 2R * asin(sqrt(sin²(Δφ/2) + cos(φ1)cos(φ2)sin²(Δλ/2)))`.

Встроенная схема карты отображает маркеры в координатной проекции. Для реальной карты используется OpenStreetMap: кнопка открывает веб-карту с текущими координатами. Поиск адреса выполняется через публичный Nominatim API и заполняет широту, долготу и метку.

## Архитектура

### Сервер

[server.py](./server.py) содержит `ChatServer`, `ClientSession`, `send_json()` и `haversine_km()`. Сервер принимает подключения, запускает поток обработки каждого клиента, регистрирует пользователей, рассылает сообщения и отвечает на запросы `location`, `users` и `nearby`.

### Клиент

[client.py](./client.py) содержит `ChatClient` с отдельным потоком чтения и `ChatWindow` — GUI на Tkinter. Окно включает ленту сообщений, список пользователей, поля координат и радиуса, схематичную карту с маркерами, открытие OpenStreetMap и поиск адреса.

### Протокол

```text
hello     {"type":"hello", "username":"Alice"}
chat      {"type":"chat", "text":"Привет"}
location  {"type":"location", "latitude":55.75, "longitude":37.61, "label":"Москва"}
users     {"type":"users"}
nearby    {"type":"nearby", "latitude":55.75, "longitude":37.61, "radius_km":5}
```

## Реализация и проверка

Автоматический [integration_test.py](./integration_test.py) запускает сервер на свободном порту и подключает двух клиентов. Проверяются регистрация Alice и Bob, отправка координат, широковещательное сообщение, поиск обоих пользователей в радиусе 5 км и корректное завершение соединений.

Результат проверки:

```text
integration_test: OK
tkinter: OK
```

Все Python-файлы также успешно прошли `py_compile`.

## Анализ

В отличие от [лабораторной №4](../Lab_04_variant_24/report.md), где процессы обменивались числовыми массивами MPI, здесь обмен выполняется через TCP и JSON-сообщения. Состояние пользователей изменяется конкурентно, поэтому сервер использует блокировки. Отдельный поток на клиента позволяет одновременно принимать сообщения и поддерживать отзывчивость GUI.

Разделение протокола на типы событий делает приложение расширяемым: можно добавить комнаты, приватные сообщения, геозоны и маршруты без изменения базового TCP-соединения.

## Выводы

Разработан многопользовательский геолокационный чат на TCP-сокетах. Сервер поддерживает несколько клиентов в отдельных потоках, хранит координаты и рассчитывает расстояния по формуле гаверсинуса. Клиент имеет GUI на Tkinter, список пользователей, текстовый чат, карту с маркерами, поиск ближайших пользователей, открытие OpenStreetMap и адресный поиск через Nominatim. Интеграционный тест подтвердил работу основных сетевых сценариев.

## Запуск

Сервер:

```powershell
python main.py server --host 127.0.0.1 --port 12345
```

Клиенты в отдельных терминалах:

```powershell
python main.py client --username Alice
python main.py client --username Bob
```

Автотест:

```powershell
python integration_test.py
```

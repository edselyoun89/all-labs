# Лабораторная работа №2 — вариант 24

Реализация таймера с отложенным запуском на Python.

## Запуск

```powershell
python main.py
python plot_graphs.py
```

Программа создаёт 10 задач с задержками от 1 до 10 секунд, отменяет последнюю задачу, записывает события в `results/logs.log`, а результаты замеров — в `results/results.csv` и `results/summary.csv`.

Все повторяющиеся измерения выполняются три раза. Фоновая нагрузка задаётся параметром `--loads`.

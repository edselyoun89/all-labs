# Лабораторная работа №7

## Тема

Парсинг сайтов.

## Задание

1. Выполнить парсинг информации с сайта по заданным параметрам.
2. Сохранить извлечённые данные в документ общего доступа из лабораторной работы 4 и в отдельный файл.
3. Предусмотреть редактирование данных парсинга в документе общего доступа.
4. Обработать ситуацию недоступности сайта и вывести сообщение об ошибке.

## Реализация

[parser.py](./parser.py) содержит `SiteParser` на базе стандартного `html.parser.HTMLParser`. Извлекаются `title`, заголовки `h1-h4`, абзацы `p` и ссылки `a`.

Параметры парсинга:

- `--keyword` — фильтр по тексту;
- `--tag all|headings|paragraphs|links` — тип извлекаемых элементов;
- `--limit` — ограничение количества элементов.

Результаты сохраняются в:

- `results/parsed_data.json` — структурированные данные;
- `results/parsed_data.csv` — табличный формат;
- `results/parsed_data.html` — редактируемый HTML-файл.

Для документа общего доступа LR_6 реализована функция `publish_to_shared_document()`. Она подключается к TCP-серверу общего документа, получает текущую версию, проверяет роль `admin/editor` и отправляет результат как новую редакцию. После публикации данные можно редактировать обычным клиентом LR_6.

## Обработка ошибок

Обрабатываются неверная схема URL, ошибки DNS/соединения, timeout, ошибки чтения, неверные параметры фильтра и отсутствие прав на общий документ. Недоступный сайт приводит к сообщению вида `Не удалось обработать сайт ...` и коду завершения 1.

## Проверка

[integration_test.py](./integration_test.py) запускает локальный HTTP-сайт, проверяет фильтр по ключевому слову, создание JSON/CSV/HTML, публикацию в сервер общего документа LR_6 и затем проверяет понятную ошибку для недоступного URL.

Результат:

```text
integration_test: OK
```

## Запуск

```powershell
python main.py https://example.com --tag all --limit 50
python main.py https://example.com --keyword example --tag paragraphs
python main.py https://example.com --shared-host 127.0.0.1 --shared-port 12346 --username Admin
python integration_test.py
```

## Вывод

Создано приложение для параметрического парсинга сайтов с сохранением в отдельные форматы и публикацией результата в общий документ LR_6. Редактирование выполняется средствами общего документа с контролем прав и версий. Обработка недоступного сайта проверена отдельным интеграционным тестом.

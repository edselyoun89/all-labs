# Лабораторная №1 — вариант 22

Решение СЛАУ методом Якоби. Основной эксперимент: **N=2000, ровно 100 итераций, p=1,2,4,8**, по три повтора. В каждом MPI-процессе работают **два OpenMP-потока** Numba; backend `omp` задаётся и проверяется явно.

## Запуск на этом компьютере

Из этой папки:

```powershell
& 'C:\Program Files\Microsoft MPI\Bin\mpiexec.exe' -n 4 ..\.venv312\Scripts\python.exe main.py --n 2000 --iterations 100 --repeats 3
..\.venv312\Scripts\python.exe run_experiments.py
```

Из другой папки передавайте абсолютный путь к `main.py`. Входные данные генерируются программой, рабочая папка не влияет на место сохранения.

## Установка на другом компьютере

Python 3.12 или 3.13, Microsoft MPI на Windows / MPI-реализация на Linux. Установите зависимости тем Python, который будете запускать через MPI:

```powershell
python -m pip install -r requirements.txt
mpiexec -n 4 python main.py
python run_experiments.py
```

При необходимости задайте `MPIEXEC` — путь к исполняемому файлу MPI. `--threads` задаёт число потоков на процесс; при изменении выше лимита Numba заранее задайте `NUMBA_NUM_THREADS` той же величиной. Число потоков должно быть не меньше двух. По умолчанию программа использует два.

## Результаты

- `report.docx`, `report.pdf`, `report.md` — отчёт с полным кодом `main.py` в приложении.
- `results.csv` — основная серия N=2000.
- `scalability.csv` — все проверенные размеры и числа процессов.
- `results/raw_p*.json` — отдельные времена всех трёх повторов и версии среды.
- `results/thresholds.json` — экспериментальный минимальный размер с E>=0.7 либо отсутствие достижения на проверенной сетке.
- `speedup.png`, `efficiency.png`, `serial_fraction.png`, `scalability.png` — графики.

`run_experiments.py` сначала проверяет N=128,256,512,1000,2000,3000,4000. Если порог достигнут, затем проверяет все меньшие допустимые размеры с шагом p. Для расширения диапазона:

```powershell
..\.venv312\Scripts\python.exe run_experiments.py --sizes 128 256 512 1000 2000 3000 4000 6000 8000
```

Размеры должны делиться на 8. Память для плотной матрицы растёт как 8*N² байт; есть также локальные копии и временные массивы. Скрипт ограничивает одну MPI-серию пятью минутами.

После уточнения минимум определяется среди допустимых N, кратных p: каждый меньший размер проверен тремя повторами. Это экспериментальный минимум текущей серии, который может меняться из-за шума коротких замеров. Если порог не достигнут, отчёт сообщает сетку проверки; размер вне неё не выдумывается. JSON хранит полный список проверенных размеров.

## Что объяснять на защите

Формула: x_i^(k+1) = (b_i - сумма a_ij*x_j^(k), j!=i) / a_ii. MPI делит строки через Scatter, OpenMP параллельно обновляет локальные строки, Allgather собирает новый вектор после каждой итерации. Начальное приближение нулевое. Изменения одной итерации не используются внутри этой же итерации.

Матрица случайная, но имеет строгое диагональное преобладание; b формируется по известному x*. Это гарантирует сходимость выбранного семейства и позволяет независимо проверить решение. Измерения исключают генерацию, JIT, проверку и запись файлов; включают Scatter, выделение локальных буферов и 100 обменов Allgather. Время Tp — максимум по процессам.

В формулах задания p — число MPI-процессов. Всего потоков 2p, поэтому дополнительно сохраняется эффективность по всем потокам. Ускорение при p=1 может быть больше единицы, так как внутри процесса два потока. B — формальная оценка модели Амдала для гибридного запуска, а не буквальная доля строк исходника.

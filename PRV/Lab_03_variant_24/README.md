# Лабораторная работа №3 — вариант 24

Параллельный поиск в базе данных с использованием `multiprocessing.Pool`.

## Запуск

```powershell
python main.py
python plot_graphs.py
```

По умолчанию создаётся база из 10 000 записей. Выполняются серии для 1, 2, 5 и 10 запросов, а также для 1, 2, 4 и 8 процессов. Каждый случай повторяется три раза. Результаты записываются в `results/results.csv`, `results/process_scaling.csv` и `results/logs.log`.

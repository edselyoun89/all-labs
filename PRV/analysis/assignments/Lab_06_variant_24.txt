Лабораторная работа №4
Тема: Документы/приложения общего доступа
Цель работы: создать документ/приложение для организации общего доступа
Задание
Создать приложение для реализации общего доступа. Приложение должно обеспечивать
совместная параллельная работа нескольких пользователей в реальном времени;
редактирование документа в режиме реального времени;
предоставление другим пользователям прав на редактирование, добавление комментариев или только просмотр;
возможность работы нескольких пользователей с разным уровнем доступа (Например, одним пользователям, может быть разрешен только просмотр данных, другим - просмотр и изменение данных)
Приложение позволяет
просматривать,
добавлять данные/информацию,
изменять данные/информацию
Отчет по выполнению задания должен включать:
Общее описание приложения. Постановка задачи, введение в предметную область.
Архитектура системы. Обоснование выбора данного типа архитектуры распределенного приложения. Алгоритм работы приложения в целом.
Архитектура каждого из логических компонент системы (серверы, клиенты, диспетчеры). Подходы к реализации. Алгоритмы работы. Многопоточность, обоснование.
Методы коммуникаций компонентов системы (клиент→сервер, сервер→клиент и т.д.). Обоснование выбора этих методов коммуникации.
Способ передачи данных (синхронная / асинхронная, однонаправленная / двунаправленная и т.д.). Обоснование.
Структура передаваемых данных. Вид протоколов, обоснование выбора (не обязательно).
Работа с базой данных (если используется). Обоснование.
Исходный код приложений с комментариями.

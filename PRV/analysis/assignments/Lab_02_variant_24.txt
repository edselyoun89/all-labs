4. ТРЕБОВАНИЯ К ПОТОКАМ
4.1. Создание потоков
Все потоки должны создаваться как наследники класса Thread.
В методе run() должна быть реализована основная логика потока.
Потоки должны иметь осмысленные имена.
4.2. Завершение потоков
Программа должна корректно завершать все потоки.
Для завершения использовать сигнальные значения (None, StopIteration).
Потоки должны быть созданы как демоны (daemon = True) или явно завершаться.

5.2. Правила использования
Lock:
Использовать конструкцию with lock: для автоматического освобождения.
Не использовать acquire() без release().
Condition:
Всегда использовать с блокировкой.
Использовать wait() в цикле для проверки условия.
Event:
Использовать set() для уведомления.
Использовать clear() для сброса события.
Semaphore:
Инициализировать с максимальным значением.
Использовать acquire() и release() парно.
Queue:
Использовать put() и get() для работы с очередью.
Использовать task_done() и join() для синхронизации.

7. ТРЕБОВАНИЯ К ЗАМЕРАМ ВРЕМЕНИ
7.1. Методы замера
Для замеров использовать time.perf_counter().
Для коротких операций использовать time.perf_counter_ns().

import time

def measure_time(func, *args, **kwargs):
    """Измерение времени выполнения функции."""
    start = time.perf_counter()
    result = func(*args, **kwargs)
    end = time.perf_counter()
    return result, end - start
7.2. Усреднение результатов
Проводить не менее 3 замеров для каждого набора параметров.
Результаты усреднять.

times = []
for _ in range(3):
    _, t = measure_time(process_data, data)
    times.append(t)
average_time = sum(times) / len(times)
7.3. Сохранение результатов
Результаты сохранять в файл results/results.csv.
Формат: threads,time_seq,time_par,speedup,efficiency

with open('results/results.csv', 'a') as f:
    f.write(f"{threads},{time_seq:.6f},{time_par:.6f},{speedup:.6f},{efficiency:.6f}\n")

import argparse

def parse_args():
    """Разбор параметров командной строки."""
    parser = argparse.ArgumentParser(description='Описание программы')
    parser.add_argument('--threads', type=int, default=5,
                       help='Число потоков (по умолчанию: 5)')
    parser.add_argument('--tasks', type=int, default=50,
                       help='Число задач (по умолчанию: 50)')
    parser.add_argument('--log', type=str, default='INFO',
                       choices=['DEBUG', 'INFO', 'WARNING', 'ERROR'],
                       help='Уровень логирования')
    return parser.parse_args()

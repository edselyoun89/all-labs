2. Запрещено использовать:
threading — заменяется на multiprocessing
asyncio — заменяется на multiprocessing

3. Требования к процессам
Все процессы должны создаваться с использованием multiprocessing.Process.
Для управления процессами использовать методы start(), join().
Для фоновых процессов использовать параметр daemon = True.
Для завершения процессов использовать метод terminate().
Для проверки состояния использовать метод is_alive().

5. Требования к синхронизации

Pipe
Двусторонняя связь между процессами

6. Требования к логированию

import logging

def setup_logging():
    logging.basicConfig(
        level=logging.INFO,
        format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
        handlers=[
            logging.FileHandler('results/logs.log', encoding='utf-8'),
            logging.StreamHandler()
        ]
    )
7. Требования к замерам времени
Использовать time.perf_counter() или time.time().
Проводить не менее 3 замеров для каждого набора параметров.
Результаты усреднять.
Сохранять результаты в файл results/results.csv.

# Лабораторная работа №1 — вариант 24

## Тема

Параллельное вычисление определителя матрицы методом Гаусса с использованием MPI и OpenMP.

## Запуск

```powershell
& 'C:\Program Files\Microsoft MPI\Bin\mpiexec.exe' -n 4 python main.py --n 1000 --repeats 3
python run_experiments.py
```

Если `mpiexec.exe` находится в другом месте, задайте переменную `MPIEXEC`.

## Реализация

- MPI распределяет непрерывные блоки строк между процессами.
- На каждом шаге выполняется частичный выбор главного элемента.
- При необходимости строки обмениваются между MPI-процессами.
- Главная строка рассылается через `MPI.Bcast`.
- Локальное исключение выполняется в Numba-функции `@njit(parallel=True)` с `prange`.
- Результат проверяется сравнением с последовательным алгоритмом.
- Для больших `N` determinant может не помещаться в `float64`, поэтому в отчёте
  сохраняются знак и `log10(|det A|)`; это эквивалентное устойчивое представление.

## Подготовленная среда на этом компьютере

В папке PRV создана `.venv312` с Python 3.12 и зависимостями для обеих новых работ. Из PRV:

```powershell
.\.venv312\Scripts\python.exe .\Lab_01_variant_22\run_experiments.py
.\.venv312\Scripts\python.exe .\Lab_02_variant_22\main.py --benchmark
.\.venv312\Scripts\python.exe .\Lab_02_variant_22\plot_graphs.py
```

Для первой работы нужен Microsoft MPI; на этом компьютере `mpiexec.exe` доступен. Перенос на другой компьютер требует установки Python, Microsoft MPI и зависимостей из `requirements.txt`.

Среды `.venv`/`.venv312` и служебные изображения проверки страниц не включены в Git. После загрузки репозитория на другом компьютере установите зависимости по инструкциям соответствующей работы; наличие локальной среды на исходном компьютере не означает её наличие в клоне.
